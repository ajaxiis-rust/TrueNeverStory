# MCP Console — ユーザーガイド

MCP Console は、TrueNeverStory のすべてのデータベースを管理するウェブベースのインターフェースです。MCP モードで `/mcp.html` にアクセスしてください。

## クイックスタート

### MCP モードの起動

```bash
TNS_MCP_MODE=1 bun run src/index.ts
```

ブラウザで `http://localhost:8000` を開きます。パスワードが設定されている場合、ログインページにリダイレクトされます。

### パスワード保護

MCP モードはメインゲームサーバーと同じパスワードを使用します。設定方法：
- **環境変数：** `AUTH_PASSWORD=パスワード`
- **設定ページ：** 設定 → 認証パスワード

パスワードが設定されていない場合、MCP モードは認証なしで動作します（ローカル開発に適しています）。

## タブ概要

| タブ | 用途 |
|------|------|
| **ダッシュボード** | データベースステータス概要（存在、サイズ） |
| **聖書** | 経文検索、キャラクター、ブートストラップ/圧縮 |
| **グーテンベルグ** | スタイル検索、デレキシフィケーション、コーパスのダウンロード/変換 |
| **カタログ** | スタイル学習用の書籍カタログの構築と管理 |
| **ウィキペディア** | 記事検索、事実検証 |
| **文学** | クエストテンプレート、コンパイル/圧縮 |
| **経済** | 経済フェーズ、ジレンマ生成 |
| **システム** | アップタイム、メモリ、操作ログ |

## カタログ — お気に入りの著者をダウンロード

「カタログ」タブでは、Project Gutenberg から個人ライブラリを構築し、スタイルストエージェントの文章品質を向上させることができます。

### ステップ 1：カタログを作成

著者名（カンマ区切り）を入力して**カタログ作成**をクリック：

```
Mark Twain, Jack London, Edgar Allan Poe
```

またはトピック（例：`adventure`、`romance`、`gothic`）を入力して著者を発見。

クイックスタートには**人気 500**をクリックして、最もダウンロードされた書籍を読み込み。

### ステップ 2：閲覧とフィルタリング

- **検索** — タイトル、著者、トピックの全文検索
- **フィルター** — 著者名、生没年範囲、最低ダウンロード数
- **ソート** — 列ヘッダーをクリック
- **ページネーション** — 前へ/次へボタンでナビゲーション

### ステップ 3：書籍を選択

- **個別** — 各書籍の横にあるチェックボックスをクリック
- **ページ全体** — ヘッダーのチェックボックスをクリック
- **フィルター結果すべて** — 「すべて選択」をクリック
- **選択解除** — 「すべて解除」をクリック

### ステップ 4：選択した書籍をダウンロード

**選択をダウンロード**をクリックして完全なテキストを取得。プロセスはバックグラウンドで実行され、プログレスが表示されます。

ダウンロード後、スタイルストエージェントが各著者のテキストから執筆パターン（語彙、文構造、感情タグ）を自動的に抽出します。

### どのように文章が向上するか

ダウンロードされたテキストは Gutenberg パーサーによって処理されます：
1. **デレキシフィケーション** — 固有名詞をプレースホルダーに置き換え、構造を保持
2. **語彙抽出** — 各著者の特徴的な語彙選択を特定
3. **文パターン抽出** — 一般的な統語構造
4. **感情タグの推定** — 暗い、明るい、ロマンチック、神秘的など

スタイルストエージェントは、ナラティブ散文を生成する際にこれらのパターンを使用し、選んだ著者の雰囲気やスタイルに合わせます。

## API エンドポイント

すべてのエンドポイントは `/mcp/` の下にあります：

| メソッド | パス | 説明 |
|---------|------|------|
| `GET` | `/mcp/status` | システムステータスとデータベース情報 |
| `GET` | `/mcp/gutenberg/catalog/stats` | カタログ統計 |
| `GET` | `/mcp/gutenberg/catalog` | ページネーションされたカタログリスト |
| `GET` | `/mcp/gutenberg/catalog/search?q=` | 全文検索 |
| `GET` | `/mcp/gutenberg/catalog/filter?author=&year_from=&year_to=&min_downloads=&subject=` | フィルタリング |
| `POST` | `/mcp/gutenberg/catalog/build` | カタログ構築ジョブを開始 |
| `POST` | `/mcp/gutenberg/catalog/select` | 個別書籍選択の切り替え |
| `POST` | `/mcp/gutenberg/catalog/select-all` | すべて選択 |
| `POST` | `/mcp/gutenberg/catalog/deselect-all` | すべて解除 |
| `POST` | `/mcp/gutenberg/download-selected` | 選択をダウンロード |
| `POST` | `/mcp/gutenberg/process` | Gutenberg 処理パイプラインをトリガー |

### POST /mcp/gutenberg/process

MCP Console から Gutenberg 処理パイプラインをトリガーします。

**リクエストボディ：**
```json
{
  "phase": "all"  // "v1" | "v2" | "all"
}
```

**レスポンス（SSE ストリーム）：**
```json
{"phase":"parse","pct":10,"message":"Parsed 45/59 books"}
{"phase":"compile","pct":50,"message":"Running DramaturgicPass..."}
{"phase":"analyze","pct":75,"message":"Analyzing chunks..."}
{"phase":"done","pct":100,"message":"Pipeline complete"}
```

**フェーズ：**
- `v1` — フェーズ A のみ（ルールベース、LLM なし）：parse → compile → done
- `v2` — フェーズ B のみ（LLM）：analyze → extract → done  
- `all` — 両方のフェーズを順番に実行

## トラブルシューティング

| 問題 | 解決策 |
|------|--------|
| カタログが空 | まずカタログを作成（著者を入力 → カタログ作成） |
| チェックボックスがリセットされる | サーバーが実行中か確認；ブラウザコンソールを確認 |
| 「認証が必要」 | 環境変数または設定で `AUTH_PASSWORD` を設定 |
| ダウンロードが固まる | システムタブ → 操作ログを確認 |
| スタイルが表示されない | ダウンロード後にグーテンベルグ変換を実行 |
