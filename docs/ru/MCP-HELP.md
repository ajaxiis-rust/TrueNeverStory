# MCP Console — Руководство пользователя

MCP Console — веб-интерфейс для управления всеми базами данных TrueNeverStory. Доступен по адресу `/mcp.html` при запуске в MCP-режиме.

## Быстрый старт

### Запуск MCP-режима

```bash
TNS_MCP_MODE=1 bun run src/index.ts
```

Откройте `http://localhost:8000` в браузере. Если пароль настроен, вы будете перенаправлены на страницу входа.

### Защита паролем

MCP-режим использует тот же пароль, что и основной игровой сервер. Настройте через:
- **Переменная окружения:** `AUTH_PASSWORD=ваш_пароль`
- **Страница настроек:** Настройки → Пароль авторизации

Если пароль не задан, MCP-режим работает без аутентификации (подходит для локальной разработки).

## Обзор вкладок

| Вкладка | Назначение |
|---------|------------|
| **Обзор** | Статус баз данных (наличие, размер) |
| **Библия** | Поиск стихов, персонажей, загрузка/компактизация |
| **Гутенберг** | Поиск стилей, делексификация, загрузка/конвертация корпуса |
| **Каталог** | Создание и управление каталогом книг для обучения стиля |
| **Википедия** | Поиск статей, проверка фактов |
| **Литература** | Шаблоны квестов, компиляция/компактизация |
| **Экономика** | Экономическая фаза, генерация дилемм |
| **Система** | Аптайм, память, логи операций |

## Каталог — Скачивание любимых авторов

Вкладка «Каталог» позволяет создать персональную библиотеку из Project Gutenberg для улучшения качества письма агента-стилиста.

### Шаг 1: Создайте каталог

Введите имена авторов (через запятую) и нажмите **Создать каталог**:

```
Mark Twain, Jack London, Edgar Allan Poe
```

Или введите тему (например, `adventure`, `romance`, `gothic`) для поиска авторов.

Для быстрого старта нажмите **Популярные 500** — загрузятся самые скачиваемые книги.

### Шаг 2: Просмотр и фильтрация

- **Поиск** — полнотекстовый поиск по названиям, авторам и темам
- **Фильтр** — по имени автора, диапазону годов жизни, минимальному числу скачиваний
- **Сортировка** — кликните по заголовку столбца
- **Пагинация** — навигация кнопками Назад/Вперёд

### Шаг 3: Выберите книги

- **По одной** — кликните по чекбоксу рядом с книгой
- **Все на странице** — кликните по чекбоксу в заголовке таблицы
- **Все по фильтру** — нажмите «Выбрать все» (применяет текущий фильтр)
- **Снять выбор** — нажмите «Снять все»

### Шаг 4: Скачайте выбранные

Нажмите **Скачать выбранные** для загрузки полных текстов. Процесс выполняется в фоне с отслеживанием прогресса.

После загрузки агент-стилист автоматически извлекает паттерны письма (словарный запас, структуры предложений, эмоциональные теги) из текстов каждого автора.

### Как это улучшает письмо

Загруженные тексты обрабатываются парсером Gutenberg, который:
1. **Делексифицирует** — заменяет имена собственные плейсхолдерами для сохранения структуры
2. **Извлекает словарный запас** — характерные словесные выборы каждого автора
3. **Извлекает паттерны предложений** — типичные синтаксические конструкции
4. **Определяет эмоциональные теги** — мрачно, светло, романтично, загадочно и т.д.

Агент-стилист использует эти паттерны при генерации нарративной прозы, подбирая настроение и стиль под выбранных авторов.

## API-эндпоинты

Все эндпоинты доступны по `/mcp/`:

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/mcp/status` | Статус системы и информация о БД |
| `GET` | `/mcp/gutenberg/catalog/stats` | Статистика каталога |
| `GET` | `/mcp/gutenberg/catalog` | Пагинированный список каталога |
| `GET` | `/mcp/gutenberg/catalog/search?q=` | Полнотекстовый поиск |
| `GET` | `/mcp/gutenberg/catalog/filter?author=&year_from=&year_to=&min_downloads=&subject=` | Фильтрация |
| `POST` | `/mcp/gutenberg/catalog/build` | Запуск сборки каталога |
| `POST` | `/mcp/gutenberg/catalog/select` | Переключение выбора книги |
| `POST` | `/mcp/gutenberg/catalog/select-all` | Выбрать все |
| `POST` | `/mcp/gutenberg/catalog/deselect-all` | Снять все |
| `POST` | `/mcp/gutenberg/download-selected` | Скачать выбранные |
| `POST` | `/mcp/gutenberg/process` | Запуск конвейера обработки Gutenberg |

### POST /mcp/gutenberg/process

Запуск конвейера обработки Gutenberg из MCP Console.

**Тело запроса:**
```json
{
  "phase": "all"  // "v1" | "v2" | "all"
}
```

**Ответ (SSE поток):**
```json
{"phase":"parse","pct":10,"message":"Parsed 45/59 books"}
{"phase":"compile","pct":50,"message":"Running DramaturgicPass..."}
{"phase":"analyze","pct":75,"message":"Analyzing chunks..."}
{"phase":"done","pct":100,"message":"Pipeline complete"}
```

**Фазы:**
- `v1` — только Фаза A (правил-based, без LLM): parse → compile → done
- `v2` — только Фаза B (LLM): analyze → extract → done
- `all` — обе фазы последовательно

## Решение проблем

| Проблема | Решение |
|----------|---------|
| Каталог пуст | Сначала создайте каталог (введите авторов → Создать каталог) |
| Чекбокс сбрасывается | Убедитесь, что сервер запущен; проверьте консоль браузера |
| «Требуется аутентификация» | Задайте `AUTH_PASSWORD` в env или Настройках |
| Загрузка зависла | Проверьте вкладку Система → Логи операций |
| Стили не появляются | Запустите Конвертацию Gutenberg после загрузки |
