# TrueNeverStory

### Пиши свою книгу просто играя.

TrueNeverStory — ИИ-движок интерактивных нарративов с **архитектурой State-First**. Каждый NPC помнит всё, каждое действие имеет детерминированный исход, а история никогда не заканчивается. Играй за персонажа, исследуй живой мир и наблюдай, как твой выбор формирует сюжет — или позволь миру развиваться самостоятельно.

Построен на TypeScript (Bun + Hono) с C FFI ядрами вычислений для критичных к производительности операций.

## Что это

Ты играешь за персонажа в постоянно живущем мире. Каждое твоё действие разбирается в структурированный интент, детерминированно симулируется и возвращается прозой через пайплайн специализированных ИИ-агентов. Внутренний язык движка — английский; перевод происходит на границе вывода, поэтому история всегда говорит на твоём языке.

- **State-First** — симуляция выполняется до написания текста, поэтому исходы детерминированы и воспроизводимы.
- **Шесть агентов, один рассказчик** — Dramaturg (архетипы), Validator (факты), Stylist (проза), Actor (NPC), Censor (стиль), Chronicler (память).
- **Литература как код** — Библия как нарративные архетипы, Gutenberg как стили прозы, Wikipedia как проверка фактов, подключено через MCP-инструменты.

## Возможности

| Область | Описание |
|---------|----------|
| **State-First пайплайн** | Детерминированная симуляция → изменение состояния → ограниченная проза |
| **Живой мир** | Персонажи, локации, фракции в графе знаний с поиском O(1) |
| **Память и RAG** | Векторная память с гибридным поиском FTS5 + dense + RRF (BGE-M3) |
| **Система вероятностей** | Детерминированные исходы боя, убеждения, скрытности, романтики |
| **Экономика NPC** | Феодальная иерархия (10 рангов), налоги, производство еды, семейная система |
| **Движок правил** | 14 социально-экономических систем с матрицей синергии |
| **Мультимир** | Изолированные миры с межмировыми событиями и порталами |
| **Стриминг в реальном времени** | WebSocket + SSE с прогрессом-сердцебиением |
| **i18n** | EN, RU, DE, FR, ES, JA, ZH |
| **Система плагинов** | Хуки жизненного цикла и API |
| **Feature Flags** | Постепенный раскат, таргетинг по проценту |

## Быстрый старт

**Не нужен ни Bun, ни Node.js, ни какой-либо рантайм.** Просто скачай и запусти.

### 1. Скачать

Возьми последний релиз для своей платформы с [GitHub Releases](https://github.com/ajaxiis-rust/TrueNeverStory/releases/latest):

| Платформа | Файл |
|-----------|------|
| Linux x86_64 | `tns-linux-x64.tar.gz` |
| Linux ARM64 | `tns-linux-arm64.tar.gz` |
| macOS ARM64 | `tns-macos-arm64.tar.gz` |
| macOS x86_64 | `tns-macos-x64.tar.gz` |
| Windows x86_64 | `tns-windows-x64.zip` |

### 2. Запустить

Лаунчер сам определяет твой LLM-провайдер (Ollama, LM Studio, OpenAI, llama.cpp), настраивает `.env` и запускает сервер.

```bash
# Linux / macOS
tar xzf tns-linux-x64.tar.gz
cd tns-linux-x64
chmod +x startgame.sh
./startgame.sh

# Windows (PowerShell)
# Распакуй tns-windows-x64.zip, затем:
.\startgame.ps1
```

### 3. Открыть

Зайди на **http://localhost:8000** — пароль: **`changeme`** (смени его в настройках после первого входа).

Всё. Без настройки базы данных, установки пакетов и правки конфигов.

## Сборка из исходников

Нужен [Bun](https://bun.sh) v1.0+.

```bash
git clone https://github.com/ajaxiis-rust/TrueNeverStory.git
cd TrueNeverStory
bun install
bun run dev        # http://localhost:8000
```

Команды: `bun run dev` (hot reload), `bun run start` (продакшен), `bun run lint` (проверка типов), `bun test` (тесты). См. [COMPILE.md](COMPILE.md) о бинарных релизах.
