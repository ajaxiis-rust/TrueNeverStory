# MCP Console — 用户指南

MCP Console 是 TrueNeverStory 所有数据库的网页管理界面。在 MCP 模式下运行时，通过 `/mcp.html` 访问。

## 快速开始

### 启动 MCP 模式

```bash
TNS_MCP_MODE=1 bun run src/index.ts
```

在浏览器中打开 `http://localhost:8000`。如果配置了密码，将跳转到登录页面。

### 密码保护

MCP 模式使用与主游戏服务器相同的密码。配置方式：
- **环境变量：** `AUTH_PASSWORD=你的密码`
- **设置页面：** 设置 → 认证密码

如果未配置密码，MCP 模式无需认证即可访问（适合本地开发）。

## 标签页概览

| 标签页 | 用途 |
|--------|------|
| **仪表盘** | 数据库状态概览（是否存在、大小） |
| **圣经** | 搜索经文、人物、引导/压缩 |
| **古登堡** | 搜索风格、去词化、下载/转换语料库 |
| **目录** | 构建和管理用于风格学习的书籍目录 |
| **维基百科** | 搜索文章、验证事实 |
| **文学** | 任务模板、编译/压缩 |
| **经济学** | 经济阶段、困境生成 |
| **系统** | 运行时间、内存、操作日志 |

## 目录 — 下载喜爱的作者

「目录」标签页允许您从 Project Gutenberg 构建个人图书馆，以提升风格师代理的写作质量。

### 第一步：构建目录

输入作者姓名（逗号分隔）并点击**构建目录**：

```
Mark Twain, Jack London, Edgar Allan Poe
```

或输入主题（如 `adventure`、`romance`、`gothic`）来发现作者。

快速开始可点击**热门 500**，加载下载量最高的书籍。

### 第二步：浏览和筛选

- **搜索** — 全文搜索标题、作者和主题
- **筛选** — 按作者姓名、生卒年份范围、最低下载量
- **排序** — 点击列标题
- **分页** — 使用上一页/下一页按钮导航

### 第三步：选择书籍

- **单本** — 点击每本书旁的复选框
- **当前页全部** — 点击表头复选框
- **筛选结果全部** — 点击「全选」（应用当前筛选条件）
- **取消选择** — 点击「全部取消」

### 第四步：下载已选书籍

点击**下载已选**获取完整文本。后台运行并显示进度。

下载完成后，风格师代理会自动从每位作者的文本中提取写作模式（词汇、句子结构、情绪标签）。

### 如何改善写作

下载的文本由 Gutenberg 解析器处理：
1. **去词化** — 用占位符替换专有名词以保留结构
2. **提取词汇** — 识别每位作者的特征用词
3. **提取句式** — 常见的句法结构
4. **推断情绪标签** — 黑暗、明亮、浪漫、神秘等

风格师代理在生成叙事散文时使用这些模式，匹配所选作者的情绪和风格。

## API 端点

所有端点位于 `/mcp/` 下：

| 方法 | 路径 | 描述 |
|------|------|------|
| `GET` | `/mcp/status` | 系统状态和数据库信息 |
| `GET` | `/mcp/gutenberg/catalog/stats` | 目录统计 |
| `GET` | `/mcp/gutenberg/catalog` | 分页目录列表 |
| `GET` | `/mcp/gutenberg/catalog/search?q=` | 全文搜索 |
| `GET` | `/mcp/gutenberg/catalog/filter?author=&year_from=&year_to=&min_downloads=&subject=` | 筛选 |
| `POST` | `/mcp/gutenberg/catalog/build` | 启动目录构建任务 |
| `POST` | `/mcp/gutenberg/catalog/select` | 切换单本书选择 |
| `POST` | `/mcp/gutenberg/catalog/select-all` | 全选 |
| `POST` | `/mcp/gutenberg/catalog/deselect-all` | 取消全选 |
| `POST` | `/mcp/gutenberg/download-selected` | 下载已选书籍 |

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 目录为空 | 先构建目录（输入作者 → 构建目录） |
| 复选框重置 | 确保服务器正在运行；检查浏览器控制台 |
| 「需要认证」 | 在环境变量或设置中配置 `AUTH_PASSWORD` |
| 下载卡住 | 检查系统标签页 → 操作日志 |
| 风格未出现 | 下载后运行古登堡转换 |
