# Wikipedia RAG — 用户指南

Wikipedia RAG（检索增强生成）会自动用Wikipedia的真实知识丰富游戏世界。当您创建世界时，系统会研究相关主题并构建一个知识库，供代理用于生成准确、详细的叙述。

## 工作原理

### 自动研究

创建世界时，系统会：

1. **提取关键词** — 从世界描述中提取（如"中世纪"、"骑士"、"英格兰"）
2. **搜索Wikipedia** — 查找相关文章
3. **解析文章** — 提取文本、章节、分类
4. **分块处理** — 分割成约500个标记的块，带有重叠
5. **构建RAG索引** — 存储块供代理查询

### 示例场景

您想要一个带有文学参考（艾凡赫、昆廷·达沃德）的**中世纪骑士**世界：

```
用户："我想要一个骑士和中世纪的世界"
```

系统自动研究：
- **地理** — 中世纪英格兰的城堡、城市、贸易路线
- **日常生活** — 食物、服装、手工艺、社会结构
- **武器和盔甲** — 剑、盾牌、锁子甲、板甲
- **统治者和指挥官** — 国王、领主、他们的性格和日期
- **灾难** — 该时代的瘟疫、火灾、地震

所有这些知识都存储在RAG索引中，供代理用于生成准确、详细的叙述。

### 空闲时丰富

当玩家超过1小时不活跃时，系统会在后台继续研究：
- 研究与世界相关的主题
- 向RAG索引添加更多细节
- 下一个代理响应使用新知识

## 进度跟踪

### Web界面

实时进度可通过SSE（服务器发送事件）获得：

```
GET /api/wiki/research/{worldId}/progress
```

进度阶段：
1. **生成世界** — LLM创建世界框架
2. **Wikipedia研究** — 下载和解析文章
3. **构建RAG** — 创建向量索引

### CLI进度

创建世界时的终端进度条：

```
[阶段 2/3: Wikipedia研究] 研究中世纪骑士精神...
  [▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓] 50% (15/30)
  → 当前：骑士
  → 错误：1（跳过：英格兰的城堡）
```

### 聊天按钮

在Web界面中，您可以控制研究：
- **🌍 研究Wikipedia** — 开始研究
- **⏸ 暂停** — 暂停研究
- **▶ 继续** — 恢复研究

## MCP集成

Wikipedia RAG可作为代理的MCP工具使用：

### Wiki搜索工具

```typescript
// 搜索相关知识
const results = await wikiSearch({
  query: "中世纪骑士精神",
  worldId: "my-world",
  limit: 10
});
```

返回：
```json
[
  {
    "article": "骑士",
    "section": "历史",
    "text": "骑士精神的概念起源于中世纪...",
    "score": 0.85
  }
]
```

### 在代理中使用

代理在生成响应时自动使用RAG：
- **剧作家** — 使用历史背景作为叙事模式
- **验证器** — 根据Wikipedia数据验证事实
- **造型师** — 用真实细节丰富描述
- **演员** — 提供关于世界的准确NPC知识

## 配置

### 重试策略

- **每篇文章5次**尝试
- **每次尝试2分钟**超时
- **指数退避**：5秒 → 10秒 → 20秒 → 40秒 → 80秒

### 优雅降级

如果Wikipedia不可用：
- 世界创建在没有Wikipedia数据的情况下继续
- 代理仅使用LLM生成的知识
- 后台重试研究

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 研究未开始 | 检查Wikipedia API的可访问性 |
| 进度卡住 | 检查系统选项卡 → 操作日志 |
| 文章未加载 | 重试策略处理临时故障 |
| 代理未使用RAG | 确保已调用`enableWikipediaResearch()` |
| "需要身份验证" | 在env或设置中设置`AUTH_PASSWORD` |

## 技术细节

### 分块策略

文章被分成约1500个字符（约500个标记）的块：
- **重叠**：块之间150个字符
- **章节**：每个章节独立分块
- **元数据**：每个块存储文章标题、章节、分类

### 搜索算法

Wiki搜索工具使用关键词匹配：
1. 将查询分成单词
2. 检查每个块中单词的存在
3. 计算相关性分数（匹配数/总单词数）
4. 返回按分数排序的顶部结果

### 存储

- **SQLite**：文章元数据和块文本
- **FAISS**：语义搜索的向量嵌入
- **按世界隔离**：每个世界有自己的RAG索引
